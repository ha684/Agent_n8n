# Agent_n8n 🤖

A powerful AI agent built with modern technologies to assist with web search and conversations through Telegram.

## 🛠️ Tech Stack

- **FastAPI** ⚡ - High-performance web framework for building APIs
- **Gemini LLM** 🧠 - Google's powerful language model for natural conversation
- **Tavily** 🔎 - Web search capabilities to find relevant information
- **Telegram** 💬 - Chat interface for user interaction
- **PostgreSQL** 🐘 - Robust database for storing conversation history and user data

## 🚀 Features

- Natural language conversations through Telegram
- Web search integration for up-to-date information
- Persistent storage of conversations and preferences
- Fast response times with asyncio-based architecture
- Easy to deploy and scale
